# VoiceBrief

PWA che trascrive e riassume i vocali di WhatsApp: li condividi all'app e ottieni testo o riassunto.

👉 https://mattiacoltelli-source.github.io/voicebrief/

- Frontend statico (GitHub Pages), pubblicato dal workflow `Deploy Pages` a ogni push su `main`.
- Backend: funzione Supabase `supabase/functions/voicebrief` (trascrizione e riassunto).
- Installabile da Chrome; la condivisione dei vocali da WhatsApp funziona dopo l'installazione.
